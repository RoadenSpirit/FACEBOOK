# FACEBOOK — Reportería y Análisis de Grupos/Páginas de Facebook

Colección de scripts en Python para la extracción, estructuración y generación de reportes ejecutivos en formato PDF sobre el rendimiento e interacciones en Facebook (páginas y grupos de Your Brand).

## Contenido

- `scrape.py`: Extracción de datos e interacciones de la página o grupo.
- `generar_pdf.py`: Motor de formateo y maquetación de informes en PDF.
- `generar_pdf_yourbrand_page.py`: Generador de reportes especializado para la entidad de la marca.
